# COVID-19-Data-Analysis                                        

A Python-based project that analyzes global COVID-19 data, visualizes trends, and forecasts future cases using Prophet and interactive plots with Plotly.

# Features

Load and process COVID-19 datasets from CSV files.

Interactive visualizations of confirmed, recovered, and active cases by country/region.

Predict future trends using Prophet forecasting models.

Simple, reusable Python script for analysis and visualization.

# Requirements

Python 3.x

pandas

matplotlib

plotly

prophet

You can install dependencies using:

pip install pandas matplotlib plotly prophet

Usage

Clone the repository:

git clone <your-repo-link>


Upload your COVID-19 dataset (CSV).

Run the Python script:

python covid19_analysis.py


View interactive plots and forecasts in your browser or notebook.
